# Explicaciones visuales

Páginas HTML autónomas que explican de forma visual los conceptos del proyecto
(algoritmos, estructuras de datos, decisiones de diseño). Cada una se abre
directamente en un navegador, sin dependencias.

Sirven como material de estudio y apoyo para la defensa: repasar el porqué de
cada pieza sin depender de prosa generada.

| Fichero | Explica |
| --- | --- |
| `dijkstra-queue.html` | Traza paso a paso de la cola de prioridad en Dijkstra |
